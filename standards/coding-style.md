# Coding Style Standard

언어별 파일을 직접 읽어라. 두 파일을 동시에 로드하지 말 것 (토큰 낭비).

## 네이밍
- 클래스/인터페이스: `PascalCase` / 메서드·변수: `camelCase` / 상수: `UPPER_SNAKE_CASE`
- 패키지: `lowercase.no.underscore`

| 언어 | 파일 |
|---|---|
| Kotlin | `standards/coding-style-kotlin.md` |
| Java | `standards/coding-style-java.md` |

언어 감지: 타겟 프로젝트의 `src/main/kotlin/` 또는 `src/main/java/` 존재 여부로 판별.
